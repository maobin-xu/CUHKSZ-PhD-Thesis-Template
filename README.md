# CUHKSZ PhD Thesis Template

You may use this template on **Overleaf** to typeset your doctoral dissertation.

Below is an overview of the core file structure:
- `main.tex`: Root master TeX file that compiles the complete dissertation.
- `setting/setting.tex`: Handles global page layout, package imports, and unified configuration for the entire thesis.
- `setting/ref.bib`: BibTeX database containing all reference citation entries.
- `setting/figure/`: Stores the university logo `CUSZ-01logo-CMYK.png`.
